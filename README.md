# Password Generator

A small Python project for generating random passwords and checking their strength.

## Features

* Generate random passwords
* Choose password length
* Choose which character types to include:

  * Lowercase letters
  * Uppercase letters
  * Numbers
  * Symbols
* Randomize generated passwords
* Check password strength
* Strength score from 0–100
* Strength levels:

  * WEAK
  * MEDIUM
  * STRONG
  * VERY STRONG
* Save generated passwords to `history.txt`
* View password history

## Menu

```text
1. Generate password
2. Check password strength
3. Password history
4. Exit
```

## How to run

Make sure Python is installed and run:

```bash
python password_generator.py
```

Then choose an option from the menu.
